# 第三方资料与代码边界

应用主体使用Python标准库和原生浏览器API，运行时没有第三方Python依赖。

- 公开商品页面只作为规格与价格观察的来源，链接和归属保留在fixtures及research中；仓库不分发商家商品图片、完整网页或品牌素材。
- 妙手、店小秘等文档用于研究财务字段类别，不是Temu官方费率或当前类目模板。
- 开发时研究过 temu-go、crawlee-python 和第三方Temu客户端，但本仓库没有复制、捆绑其源码、安装程序或账户配置。
- 截图由本项目运行页面生成，展示预算案例，不包含真实卖家账号。
- GitHub Actions使用官方checkout及setup-python动作，仅用于源码验证。

项目没有在本次发布中擅自指定开源许可证；代码公开不等于授予任意再分发许可，后续许可由仓库所有者决定。
