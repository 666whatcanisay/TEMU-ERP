经营测算

供货收入 P 与可变成本 C 必须使用同一币种、同一销售单位。收入贡献率 = (P − C) / P；成本加价率 = (P − C) / C。二者分开。尚未录入的固定人工、租金和税不包含在贡献额中。

收入贡献率门槛 t 对应的最低供货价为 C / (1 − t)；成本加价率门槛对应 C × (1 + t)。最低价向上取至分，门槛比较使用未舍入金额。40%、50% 等由公司自行确定，不是平台统一规则。

金额、凭证和政策未确认时可看测算，但不标为已核验达标。改动金额、币种、单位或凭证后须重新确认。来源为本工具的内部计算契约，可在设置中查看和调整公司政策。

商品与 SKU

产品、SKC、SKU 的平台 ID 只保存平台返回的原始字符串，未知留空。商家编码由内部定义；ORG-HONEY-BRN-06 是便于仓库识别的建议命名，不是官方强制格式。同一商品内商家 SKU 必须唯一。

件数按每个销售单位定义，套装组成数量合计等于件数是本工具的一致性校验。单件、销售单位本体、运输包装分开存储；本工具统一以 cm、g 录入，外部模板的单位换算由适配器处理。毛重不可小于净重。

店小秘：产品货号、变种信息、供货价、尺寸、净重、包装重量 · 妙手：SKU 分类、包装清单、净重与毛重

两者是 ERP 厂商的实现文档。标题字符数、变种数、图片阈值、必填性和枚举不得据此认定适用于所有店铺。当前公司真实类目模板具有优先级。

市场证据

按 SKU 对账国家、观察日期、件数、材质、尺寸及组成。缺失为“资料不足”，明确不同为“规格不同”，信息齐全且一致才为“规格可比”。可比不等于同厂同款、畅销或需求成立。德国零售价格与人民币供货收入分别保留；未经汇率、税费与履约成本核对，不计算所谓平台利润。

评价、排名、搜索趋势均不换算成月销量。未观察到有统计窗口的销量就留空。
